Assignment 2 Documentation
**************************

This is the documentation of the second assignment of RT1. It consists of a briefly explanation of the two modules integrated inside the package: Target_client and Service_node. This package allows an user to freely set a target for the robot to reach, modifying it or cancelling it (even during the execution of the command)
